# Module 2: Retrieval-Augmented Generation (RAG) Architecture

## Key Concepts
- **Chunking**: The process of breaking down large documents into smaller, meaningful paragraphs or sentences. Optimal chunk sizes balance context preservation with retrieval precision.
- **Embeddings**: High-dimensional vectors generated by models like `text-embedding-004` that capture semantic meaning. Similar concepts sit closer together in vector space.
- **Vector Database**: A specialized database (like ChromaDB) designed to index, store, and perform fast similarity searches on vector embeddings.

## Technical Requirements
- Embedding Model: `text-embedding-004` (via the `google-genai` SDK)
- Local Store: ChromaDB (Persistent client mode)
- Prompt Engineering: Inject retrieved documents directly into the Gemini system prompt using clear delimiters like `<context></context>`.
